# 截图、长图与区域录制

Sticky 0.7.0 内置原 cut 0.16.0 的截图功能。无需启动 Cut.exe，也不依赖 cut 源码目录。完整 Windows x64 便携包包含离线 OCR、二维码识别及录制组件。

## 入口与设置

- 全局快捷键默认为 **Ctrl+Alt+A**，也可从管理页「截图与录制」、托盘「开始截图」或设置页启动。关闭管理页后快捷键继续可用。
- 「设置 → 截图与录制」：快捷键、注册状态、录制默认帧率、指针和倒计时，以及截图文字 AI 的连接来源。
- 「设置 → 识别与翻译」：Azure Translator 地址、Region、密钥、连接测试。OCR 自身完全离线。
- 「设置 → AI 接入」分为便签 AI、截图文字 AI、截图视觉 AI。截图文字 AI 可独立配置，也可在截图设置中显式选择复用的便签 AI 连接；视觉 AI 可独立配置或沿用截图文字 AI 地址与密钥，并使用自己的视觉模型。
- 自启动、托盘、单实例和版本更新统一由 Sticky 管理。截图、识别、长图编辑、录制或导出未结束时不能重启更新；请先在任务窗口完成或取消。退出会保护正在进行的任务和未保存的标注。
- 截图工具仅禁用自己的父工具窗口，长截图和录制期间普通 Sticky 便签保持可操作，也可作为采集目标。

截图配置保存在当前数据目录的 `device/capture`，仅本机使用，不随 Git 同步。密钥使用 Windows 当前用户 DPAPI 加密。便签原有的 AI 配置和同步规则保持兼容；独立截图配置不会覆盖便签 AI 的密钥。

## 截图与标注

进入截图后桌面冻结。悬停预选窗口，单击确认；拖动可自由框选，再移动或调整选区。支持多显示器、负坐标、跨屏物理像素裁剪；显示器之间的空隙为黑色。普通 Sticky 便签仍可被窗口预选，截图工具窗口被排除。

| 操作 | 快捷键或入口 |
| --- | --- |
| 复制图片 | Enter、Ctrl+C 或非绘图状态双击选区 |
| 保存 PNG | Ctrl+S |
| 二维码识别 | Ctrl+Q |
| 中英文离线 OCR | Ctrl+T |
| AI 看图 | Ctrl+I |
| 长截图 | Ctrl+L |
| 区域录制 | 工具栏录制按钮 |
| 标注撤销／重做 | Ctrl+Z／Ctrl+Y |

支持矩形、椭圆、箭头、画笔、文字、马赛克和实色遮挡；已有对象可选择、移动、调整样式和删除。文字输入 Enter 换行、Ctrl+Enter 提交，Esc 放弃当前编辑。右键退出绘图并保留已完成标注，再次右键重选，无选区时退出。复制、PNG、OCR、二维码和 AI 看图使用同一份标注后的合成图。

截图结果默认只在会话中保留。复制图片后可粘贴进便签；只有明确保存或插入便签的图片才进入文件或便签资产、历史与同步。没有额外自动保存用户截图的历史库。

## 识别、翻译与 AI

二维码支持多码、复制内容及用系统浏览器打开 HTTP/HTTPS 网页。OCR 支持中英文混排、原图预览、编辑、复制选区／全文、合并换行和撤销。

翻译只发送选中的文字或全文；截图文字 AI 发送 OCR 校对后的文字与问题；视觉 AI 发送预览的图片与问题。均需用户点击操作才发送，不自动上传截图。AI 保留解释、报错分析、摘要、润色、自定义问题和视觉界面／图表分析，以及流式输出、停止和编辑复制。连接测试使用固定合成文字或程序生成的验证码图，不发送用户桌面。

OCR 上限为 1600 万像素；标注为 3200 万像素；视觉图片输入在 3200 万像素以内，编码时长边最多 4096、PNG 最多 4 MiB。超长图片可先局部裁剪。

## 滚动长截图

在同一显示器内框选至少 128×160 物理像素，选择向下网页或向上聊天历史，可排除上下固定栏。支持手动滚动、自动滚动三档速度、暂停／继续、撤销最近拼接和完成后编辑。自动滚动根据实际位移和稳定帧调整输入，鼠标离开、失焦、用户接管或目标窗口变化时暂停。

「允许低置信度拼接」仅对本次任务生效，默认关闭；开启可能导致重复、缺行或错位，采集和编辑窗口保留检查提示。完整原图缓存最多 1 GiB。完成后可缩放、标注、局部裁剪，并复制、保存、OCR 或 AI 看图；不会把已有普通截图标注带入重新采集的实时长图。

## 区域录制

在单个显示器内框选至少 16×16、最多 829 万物理像素，选择 5／10／15／30／60 FPS。默认 30 FPS、录制指针、3 秒倒计时，可在统一设置中调整默认值。固定区域最长有效录制 60 秒，无声音；暂停时间不计入成片。

F8 停止并预览，被占用时尝试 Ctrl+Alt+F8，两者均被占用则拒绝开始。录制优先使用 Windows Graphics Capture，失败时回退 GDI。实际帧率取决于系统与负载。

停止后支持缩略图时间轨道、独立播放头、首尾裁剪、逐帧和十帧键盘调整、恢复全段。可导出 GIF 或 H.264 MP4、原尺寸／75%／50%、输出帧率和画质。MP4 无音频，奇数宽高补黑边。取消保存、取消导出和失败均保留预览供重试；关闭未导出结果前会询问。

临时缓存使用独立 `Sticky-capture-recording-*` 目录和活动租约，最多 1 GiB；正常关闭清理，启动清理本模块未被占用的遗留缓存。显示器布局变化会取消任务，锁屏或远程会话断开暂停录制。不支持退出后恢复录制。

## 从 cut 导入

「设置 → 数据与备份 → 导入 cut 设置」默认读取 `%LOCALAPPDATA%/Cut`，也可指定旧配置目录。导入快捷键、文字 AI、视觉 AI 和翻译配置；默认跳过 Sticky 中已有项，勾选替换后会确认。配置按项验证，密钥解密后重新加密，错误会列出且保留已有效的配置。原 cut 文件、自启动项和更新配置不会被修改。

如果 cut 与 Sticky 同时运行，可能占用相同快捷键；设置会显示注册结果，可退出其中一个或改键。其他 Windows 用户的旧密钥需要重新填写。

## 开发与发布

```powershell
./scripts/download-ocr-models.ps1
./scripts/download-recording-tools.ps1
./test.ps1
# 解锁桌面，测试会临时移动鼠标并恢复；仅采集合成窗口
./scripts/test-capture.ps1 -NoBuild -Native
./scripts/package-portable.ps1 -OutputDirectory ./dist/新目录
```

截图实现位于 `src/Sticky.Capture`；原 cut 功能测试迁入 `tests/Sticky.Capture.Tests`，主机集成测试在 `tests/Sticky.Tests/CaptureIntegrationTests.cs`。测试输出位于截图测试目录的 `artifacts` 及 Sticky 隔离测试目录。真实网页样本回放／基准测试需要另行提供原有样本，不纳入默认回归。

发布保留单文件主程序和旁置 Models、MediaTools、许可文件、原生依赖与 VC++ x64 运行库，所有内容加入版本清单。首次安装／更新试启动会执行本地合成 OCR、校验并启动 ffprobe，失败不会提交新版本；已确认版本按需初始化识别引擎。完整包体积会大于原便签版本。

Windows 10／11 x64、混合 DPI 多屏、HDR、受保护视频及不同真实目标应用仍需按硬件验收；自动化合成测试不代表所有显卡、应用和显示器组合已验证。第三方组件来源与许可证随包保存。
