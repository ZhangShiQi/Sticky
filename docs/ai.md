# AI 接入与自定义功能

自 0.6.0 提供 AI 接入与自定义功能。支持 OpenAI 兼容的 Chat Completions 文本接口；原生 Responses、Anthropic Messages、Gemini 等不同协议需通过兼容接口使用。

## 配置和使用

1. 在「设置 → AI 接入 → 连接与思考」填写 API 地址、模型 ID 和本机密钥，勾选启用后保存。API 地址可为包含 `/v1` 等服务路径的 Base URL，也可为完整 `/chat/completions` 地址。程序不会自动选择模型。
2. HTTPS 服务需要 API 密钥；本机 `localhost`、`127.0.0.1`、`[::1]` 可以使用 HTTP 和空密钥。可配置 5–180 秒超时，默认 60 秒。
3. 「测试连接」只发送固定示例文本，不发送便签、不保存未提交的表单，也不自动启用功能。调用费用和内容处理政策由所选服务商决定。
4. 在「自定义功能」新增按钮：填写名称和提示词，选择预设 SVG 图标并保存。提示词例如「翻译成英文，语气专业」或「提炼三个要点」，选中文字会单独附上，无需占位符。提供润色、翻译、摘要、清单、灵感、正式表达、代码及通用星光八种图标。内置「语法修正与润色」也可以编辑、停用或删除。
5. 在便签中选中文字，点击底部工具栏「AI」，列表显示已启用的功能。选择功能后打开预览并发起一次请求；左侧原文、右侧结果，结果可以编辑，点击「替换原选区」才修改正文。关闭窗口取消，错误不会替换原文；手动重新生成会发起新请求。没有选中文字时仍可打开菜单进入设置，文字操作暂不可用。
6. 替换是一个可撤销的编辑，保留选区两端空白及选区外内容/图片；选区内文字采用起始处的文字样式，不逐字映射原有混合格式。修改经原有自动保存与 GitHub 同步逻辑处理，并以「AI · 功能名称」记入本地历史。

## 思考模式

开关默认关闭，普通语法修正与润色无需开启。不同服务的控制协议不同：

| 格式 | 关闭 | 开启 |
| --- | --- | --- |
| 自动识别 DeepSeek 官方接口 | 官方 `api.deepseek.com` 发送 `thinking: {type: "disabled"}`；其他地址不发送参数 | 官方接口发送 `thinking: {type: "enabled"}`；未识别的服务需先选择格式 |
| DeepSeek 格式（含自定义代理） | `thinking: {type: "disabled"}` | `thinking: {type: "enabled"}` |
| reasoning_effort 格式 | `reasoning_effort: "none"` | `reasoning_effort: "high"` |
| 不发送参数，由服务商决定 | 不发送思考参数 | 需先选择受支持格式，才可开启 |

模型必须支持所选格式及取值。自动识别不根据模型名称猜测代理协议；未知服务未发送参数时，实际行为取决于服务商默认设置。思考开关属于连接参数，适用于该连接的所有操作。

## 多设备配置同步

- 在原有 GitHub 同步启用后，连接地址、模型、超时、思考开关及控制格式，自定义按钮的名称、提示词、图标和启用状态都会同步。不需要另配一个仓库，也不会通过 AI 服务保存这些配置。
- 共享配置在 `Data/ai.json`，仓库中位于独立的 `sticky-ai-v1/settings.json`。旧版客户端仍可同步便签，并保留这个独立目录；管理 AI 配置需要升级客户端。
- API 密钥只在 `Data/device/ai.json`，通过 Windows DPAPI 当前用户加密，绑定完整的 API 请求地址。新设备先获得共享配置，再填写本机密钥；密钥缺失时可以正常记便签，AI 请求不可用。移除本机密钥不会关闭其他设备。
- 同一功能或连接同时修改时保留双方，另一份标注「冲突副本」；连接下拉框可选择本机使用的版本。删除功能保留删除记录，另一台设备同时编辑时保留其活动副本。重复同步不会重复生成相同副本。
- 设置窗口收到同步后会提示更新，不覆盖尚未保存的草稿；保存时再次合并并发修改，也可主动「载入已保存配置」。未启用同步或断网时，配置照常本地保存，重连后同步。
- 旧版仅本机 AI 配置会自动迁移，保留其原有加密密钥；思考模式保持默认关闭。

## 数据和失败行为

- 请求只包含文本处理约束、该功能的提示词、选中文字和配置的模型 ID，不附带便签标题、整篇内容、图片、其他便签或历史版本。待处理文字以单独的用户消息提交，返回结果也只作为普通文字插入，不执行 HTML、XAML、程序或脚本。图标来自内置 SVG 预设，不执行外部 SVG。
- 支持 1–20,000 字符选区，响应读取最多 2 MiB，结果最多 60,000 字符。包含图片的选区需先缩小到纯文字；截断、拒绝、空响应和不兼容格式都拒绝替换。
- 每次只发出一个请求，不自动重试计费请求，也不跟随 HTTP 重定向转发密钥。错误信息不显示服务商的原始响应或密钥。断网、请求取消或超时不影响本地编辑和保存。
- 润色绑定打开窗口时的原选区。若期间原文、格式或文档被修改（包括同步替换正文），确认时阻止覆盖。可复制已生成结果，关闭后重新选取文字。
- 空密码框表示保留原密钥，更改地址必须重新输入。复制便携目录到其他电脑或 Windows 用户后，需要重新配置密钥。密钥不进入 GitHub 同步、普通便签备份或完整历史备份。程序更新的数据快照可能包含本机加密配置，以便恢复本机状态。
- 普通便签备份、完整历史备份仍只备份便签及历史，不包含共享 AI 配置；保留完整 `Data` 目录或使用 GitHub 同步保存共享配置。损坏或不支持的共享配置拒绝同步，不用空配置覆盖正常数据。

## 验证

模拟 HTTP 测试覆盖思考参数、自定义提示词、选区请求范围、模型、错误脱敏、重定向、取消、超时、响应大小和截断；实际 WPF 测试覆盖功能编辑、SVG 图标、菜单、草稿保留、设置密钥保留/清除、预览确认、原选区替换、图片和样式、撤销、过期选区保护及历史记录。真实本地 Git 多设备测试覆盖共享配置往返、密钥隔离、断网重启、冲突收敛、删除与编辑冲突及损坏配置拒绝。没有使用真实 API 密钥执行收费请求，具体服务商和模型的效果应在配置后通过「测试连接」及实际操作确认。
