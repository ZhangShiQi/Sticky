Sticky {{VERSION}} · Windows x64 便携版

开始使用
1. 将 ZIP 完整解压到一个可写目录，例如 D:\Apps\Sticky。不要直接在 ZIP 预览中运行。
2. 双击 Sticky.exe。无需安装 .NET SDK、.NET Runtime 或 Git。
3. 标题栏默认始终显示，顶部展示实际标题，长标题省略并可悬停查看完整内容。「设置 → 编辑与排版」可开启自动隐藏，阅读空闲时收起为窄色条，可选择悬停展开；悬停不进入编辑。点击正文后顶部栏保持显示，输入法候选框不会造成正文跳动。切换窗口或按 Esc 完成编辑。
4. 没有手动标题时，使用正文第一行有效文字作为标题，输入和同步后及时刷新；清空手动标题可恢复此规则。
   双击图片可打开预览窗口，支持滚轮/按钮缩放、适应窗口、1:1 查看和放大后拖动；点击外部失去焦点、按 Esc 或关闭所属便签时关闭预览。查看不改变便签内图片的大小和正文。
5. 左侧「工作空间」统一列出全部便签、各分组、未分组、回收站；底部搜索框输入后按回车打开结果。
6. 左下角「设置」包含同步、数据与备份、编辑与排版、应用、版本与更新、历史与重放、AI 接入七个分类。
7. 新建便签默认随机选择颜色；顶部「保存状态」与「···」之间的颜色方块也可快速更改颜色，选中后自动保存。
8. 「设置 → 编辑与排版」可统一调整默认字号和段落间距，保存后立即应用；新建和重开保持一致，手动设置过字号的文字保留原大小。
9. 「设置 → 应用 → 开机自动运行」默认关闭，勾选后在登录 Windows 时恢复便签，管理页留在托盘；取消勾选即可关闭。
10. 「设置 → 版本与更新」默认自动检查并下载正式版本，保存并退出时安装并重新启动；也可立即重启更新或关闭自动更新。个人便签与同步仓库不参与程序替换。旧版 0.1.x 需手动升级一次。
10. 便签左上角「＋」和 Ctrl+N 会在当前便签附近新建，连续新建时自动避让其他已打开的便签，利用左右、上下及周围空隙；空间紧张时缩小间距，附近放不下才错开叠放。最小化或隐藏的便签不占位置；已有便签位置保持不动，保持当前分组，并限制在当前显示器的工作区内。
11. 「设置 → 编辑与排版」包含随机颜色、自动隐藏标题栏和隐藏时悬停显示开关；自动隐藏默认关闭。点击「保存并应用」后对现有便签生效，重启保留，仅保存在本机。
12. 当前 Windows 用户会话内只保留一个运行实例；重复双击 exe 会唤起现有管理页，新进程随即退出。切换数据目录或移动到新目录前，请先退出正在运行的 Sticky；升级前也请先退出旧版本。
13. 管理页「时间轴」、便签「··· → 历史版本与重放」可查看本地历史。左侧多选便签，顶部统一显示时间，工作空间和便签轨道共用 SVG 操作图标；悬停查看说明，点击节点精确回看。播放、暂停、倍速和拖动进度均只影响历史预览，恢复为副本或恢复当前便签都会新增历史记录。
14. 历史保存在 Data\history，不依赖 GitHub，也不上传 GitHub。时间轴中的「导出历史」可备份完整本地历史；恢复时退出 Sticky，将 ZIP 完整解压到新的空 Data 目录。普通便签导入不用于合并历史。

AI 接入与自定义功能
在「设置 → AI 接入 → 连接与思考」配置兼容 OpenAI Chat Completions 的 API 地址、模型、本机密钥，启用并保存。思考模式默认关闭，DeepSeek 官方接口自动发送关闭参数；其他接口可选择其支持的参数格式。测试连接仅发送固定示例文本。
在「自定义功能」中新增或编辑按钮名称、提示词和预设 SVG 图标，可停用或删除。选中文字后点击便签工具栏 AI，从列表选择功能，检查或编辑结果后确认替换；支持撤销和本地历史。请求只包含该功能的提示词与选中文字，不发送整张便签或图片。断网、取消或超时不会替换原文，也不影响本地编辑保存。
连接参数、思考开关、提示词、图标和启用状态随 GitHub 同步；并发修改保留冲突副本，删除记录也会同步。API 密钥按当前 Windows 用户加密，只留在本机，不参与 GitHub 同步或便签备份；新设备需填写本机密钥。移除本机密钥不影响其他设备。普通便签/历史备份不包含 AI 设置，需保留完整 Data 目录或使用 GitHub 同步保存共享配置。

文件与数据
启动优化：已确认版本在界面就绪后立即可用，稳定性观察继续在后台完成；首次安装或更新试启动仍保留禁用编辑的保护窗口。启动期间显示正常界面提示，不再显示透明黑屏。开机启动不会闪出管理页。
并行启动：程序校验最多并行 4 个任务，文件数据加载与界面构建同时进行，恢复多张便签时合并布局写入和列表刷新；仍完整校验所有组件，所有窗口只在界面线程创建，数据准备完成前不会开放编辑。
默认使用 ReadyToRun 预编译减少部分即时编译开销，仍包含 .NET 运行时和完整 WPF 功能，无需安装 SDK。首次和更新试启动的安全确认仍保留。
这次包含稳定启动器优化，请先退出旧版，将新包完整解压后迁移自己的完整 Data；不要只替换 tools 中的内部 exe，原安装目录请保留以便回退。
根目录 Sticky.exe 是稳定启动器，已包含 .NET 运行时；tools 目录包含 WPF 程序、Git 和 Git Credential Manager。必须完整解压，不要只复制 exe。
新便签、图片、分组和本机同步配置保存在 Sticky.exe 旁边的 Data 文件夹。
发布包不包含开发机上的便签、同步配置或账号凭据，首次启动是空白工作空间。
复制整份目录可携带数据；更新程序时请保留自己的 Data、.sticky-launcher 和 versions 文件夹。
自动更新使用独立版本目录；新版通过启动确认后才启用编辑。启动失败会恢复试启动前的数据并运行旧版，相同失败包会停止重复安装。
若更新中途退出或被强制终止，再次双击根目录 Sticky.exe 即可继续恢复。不要删除 .sticky-launcher 中的事务、快照或旧版本。
已确认更新后再回退程序时，保留你后来新增的便签，不会套用旧快照。
不要把目录放在 Program Files 等普通用户不可写的位置。
开机启动项记住当前程序和数据目录，仅对本机当前 Windows 用户生效，不随 GitHub 或 Data 复制；移动目录或升级到其他目录后，请在新位置重新开启，替换旧启动项。
若 Windows 的启动应用设置禁用了 Sticky，请在系统设置中重新允许它运行。
应用图标统一为墨绿与暖黄折角便签；SVG 源文件附在 assets\Sticky.svg。

测试两台电脑同步
1. 两台电脑分别解压完整发布包，不要只复制 exe（同步还需要 tools）。
2. 打开「设置 → 同步」，填写同一个私有仓库 HTTPS 地址和同步分支。
3. 勾选启用，点击立即同步，在各电脑分别完成 GitHub 登录。
4. 凭据由各电脑的 Windows 凭据管理器保存，不放在 Data 中；复制目录后可能需要重新登录。
5. 编辑始终先存本地，断网仍可记录；同一便签双端改动时生成冲突副本，保留双方内容。
默认分支为 sticky-data。同步便签、分组、图片和回收站，不同步窗口位置和本机凭据。

退出与备份
关闭管理窗口后，便签和托盘进程仍继续运行。
彻底退出请使用「设置 → 应用 → 退出 Sticky」或托盘中的退出入口，退出后再复制或移动整个目录。
可在「设置 → 数据与备份」导出/导入 ZIP；原开发预览的数据可先导出，再导入便携版。
自动 .bak 备份统一放在 Data\backups 中，按原路径分类；升级时自动迁移旧版并排保存的 .bak，遇到同名备份保留双方内容。
损坏原文件保存在 Data\backups\corrupt 中；可从设置中的「打开自动备份目录」查看。
默认字号与段落间距保存在 Data\device\editor.json，仅影响此设备，不随 GitHub 同步。

说明
这是 Windows x64 版本。运行时的本机库可能会解压到系统临时目录，这是单文件发布的正常行为。
本地数据和仓库内容为明文。私有仓库提供访问控制，没有端到端加密。
第三方许可证和来源见 licenses，Git 自带组件的许可证也保留在 tools\git 内。
